# ASO-оптимизация листинга ProxyPilot (Chrome Web Store + Firefox AMO)

**Дата:** 2026-06-24
**Статус:** рекомендации на ревью
**Контекст:** монетизация = функция роста базы (брейншторм 2026-06-23/24). База 500–5k; цель — рост установок. ASO выбран первым рычагом: конверсия листинга умножает все источники трафика (YouTube 58%, Direct 30%, Referral 7%) сразу. Опирается на аудит `aso-listing-audit` (текущие тексты, факторы CWS/AMO 2026, ключевые слова, конкуренты). Юр-рамка: ФЗ 332-ФЗ — никаких «VPN/обход/unblock» (см. [[youtube-channel]] не относится; см. ресёрч закона). Принцип [[project-simplicity-principle]] на листинг не влияет, но тексты держим нейтральными как в 0.15.1.

## Главный вывод аудита

**Фактор ранжирования №1 в CWS — точное вхождение ключа в ЗАГОЛОВОК** (title > summary > первый абзац описания). Сейчас заголовок = «ProxyPilot» — чистый бренд без единого поискового ключа. По нему не ищут. Это главная упущенная возможность. Конкурент-лидер по этому приёму — «Proxy Switcher and Manager» (оба ключа в title).

**Технический факт (проверено):** `app_name` используется только в `manifest.json` (`name` + `action.default_title`), НЕ в попапе. Значит добавление ASO-дескриптора в заголовок меняет название в сторе/`chrome://extensions` и тултип иконки, но **не раздувает UI попапа** — бренд «ProxyPilot» в интерфейсе остаётся. Риска для UX нет.

## Факторы (кратко, по аудиту)

Ранжирование CWS: 1) релевантность title→summary→1-й абзац; 2) еженедельные активные юзеры; 3) рейтинг 4.5+ и свежесть отзывов; 4) скорость роста установок; 5) CTR листинга; 6) % удалений; 7) частота обновлений; 8) MV3 (уже ✓).
Конверсия: иконка, summary (виден в поиске), первый скриншот, рейтинг, промо-тайл 440×280, первый абзац описания.
Лимиты: CWS title 75 (видимо ~35), summary 132. AMO summary 250, name без жёсткого лимита, поддержка Markdown (с 03.2025), 2 категории, аудитория Firefox Android. Keyword spam (>5 повторов ключа) — нарушение.

## Рекомендация 1 — Заголовок (главный рычаг)

CWS берёт title из `manifest.name` (= локализованный `app_name`). Добавляем дескриптор с топ-ключами, бренд оставляем первым.

**EN `app_name`** — варианты (рекомендую A):
- **A:** `ProxyPilot — Proxy Manager & Smart Routing` (43 симв) — частотные «proxy manager» + «routing».
- B: `ProxyPilot — Proxy Switcher & Manager` (38) — два самых частотных запроса ниши.
- C: `ProxyPilot — Per-Site Proxy Manager` (35) — уникальное отличие (per-site).

**RU `app_name`** (рекомендую): `ProxyPilot — менеджер прокси` (28). Альтернатива: `ProxyPilot — прокси-менеджер и маршрутизация`.

Видимое окно в поиске ~35 символов — бренд короткий, ключ попадает в зону видимости. Keyword spam не нарушается (каждый ключ ≤1 раза).

> ⚠️ В `messages.json` у `app_name` стоит пометка «Brand name — keep as-is». Это сознательное решение — **требует твоего согласия** на добавление дескриптора. Бренд в UI не меняется (см. техфакт выше), меняется только store-title.

## Рекомендация 2 — Краткое описание (summary, виден в поиске)

Ключи в начало. Проверить точную длину ≤132 (CWS) перед подачей.

**EN** (≈120):
> Per-site proxy manager & switcher: route only the sites you choose through your HTTP/SOCKS5 proxy — the rest goes direct.

**RU** (≈118):
> Менеджер и переключатель прокси: только выбранные домены идут через ваш HTTP/SOCKS5-прокси, остальной трафик — напрямую.

(CWS summary = локализованный `manifest.description` = `app_description` в `messages.json`. AMO summary отдельный, лимит 250 — можно длиннее, текущие RU/EN ок, добавить ключ «proxy manager / менеджер прокси» в начало.)

## Рекомендация 3 — Первый абзац полного описания

Алгоритм весит его выше остального текста. Начать с ключей + пользы.

**EN:**
> ProxyPilot is a per-site proxy manager and switcher. Route only the sites you choose through your own HTTP/HTTPS/SOCKS5/SOCKS4 proxy (or a curated free pool) — everything else connects directly. No account, no tracking, all local.

**RU:**
> ProxyPilot — менеджер и переключатель прокси по доменам. Через ваш HTTP/HTTPS/SOCKS5/SOCKS4-прокси (или подобранный бесплатный пул) идут только выбранные сайты — остальной трафик напрямую. Без аккаунта, без слежки, всё локально.

Остальное тело описаний (возможности/пул/блоклист) — оставить как есть, оно хорошее.

## Рекомендация 4 — Ключевые слова для тела описания

Вплести естественно (плотность 2–3%, без спама). Все проверены как нейтральные (legalSafe):

- **EN:** proxy manager, proxy switcher, per-site proxy, SOCKS5 proxy, HTTP proxy extension, proxy profile, automatic proxy switching, PAC script, URL pattern routing, proxy pool, proxy rotation, browser proxy manager, proxy settings.
- **RU:** менеджер прокси, прокси переключатель, настройка прокси в браузере, маршрутизация трафика по доменам, SOCKS5 прокси расширение, пул прокси, авто-ротация прокси.

## Рекомендация 5 — Категория и теги

- **CWS:** Productivity (оставить) — категория не главный сигнал, менять не нужно.
- **AMO:** Privacy & Security (одна категория; Mozilla не советует вторую без нужды).
- **AMO теги:** `proxy, socks, http proxy, proxy manager, routing`. **Убрать тег `vpn`** из `docs/firefox-amo/PUBLISHING.md` — он противоречит позиционированию (в 0.15.1 чистили «no VPN»), юр-рискован и тянет под VPN-классификатор. Это также чинит расхождение между `amo-listing.md` и `firefox-amo/PUBLISHING.md`.

## Рекомендация 6 — Скриншоты (восстановлено вручную)

Из аудита: RU-набор = 3 скриншота (01-main, 02-free-pool, 03-active-source) + 2 промо; **EN-набор беднее** (нет en/03, нет EN promo-440).

- **Первый скриншот** — решает конверсию за 1 сек. Сейчас «главный экран». Усилить **аннотацией-оверлеем** с выгодой: «Включи нужный сервис — он открывается через прокси. Остальное — напрямую» / EN «Turn on a service — it opens via proxy. The rest stays direct.» Топ-конкуренты используют аннотированные скриншоты.
- **EN-паритет:** добавить `en/03-active-source` и EN-промо 440×280 — англоязычная карточка не должна быть беднее русской (EN-аудитория — зона роста).
- Порядок: 1) ценность (выбор сервиса), 2) три источника прокси, 3) бесплатный пул + предупреждение, 4) тёмная тема/статус «что работает». About-экран в сторе не нужен.
- Промо-тайл 440×280 — заполнить и для EN (виден в категориях/на главной).

## Рекомендация 7 — Рейтинг и отзывы (связка с виральностью)

Рейтинг 4.5+ и свежесть отзывов — фактор ранжирования №3 и сильный конверсионный сигнал. Это отдельная инициатива — **review-nudge в момент ценности** (по паттерну `donate`-баннера: uses≥N, раз в 14 дней, dismissible). Спроектировать отдельным документом; здесь — только отметка, что это часть той же ASO-петли (отзывы → ранжирование → установки).

## Чего НЕ делать (юр + политика)

- **Запрещённые слова** (юр-риск ФЗ 332-ФЗ + VPN-классификатор стора): VPN, unblock, bypass, обход, разблокировать, anti-censorship, hide IP, tunnel, Tor, geo-unblock, «доступ к заблокированным» и т.п. (полный avoid-список — в аудите).
- **Keyword spam** — не повторять один ключ >5 раз; плотность 2–3%.
- Не позиционировать как «обход блокировок РКН» нигде в листинге.
